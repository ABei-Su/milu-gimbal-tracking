# 测温状态与故障处理

不持久化状态。重启从人工选择、TRACK OFF、INVALID开始，不恢复旧目标或温度。所有时间为同一机器单调时钟秒；温度单位℃。主进程串行决策，不由传感器线程修改状态。

## 选择状态

SELECTING → 按下图像 → DRAGGING；松手有效矩形 → TRACKING，新session；太小矩形 → SELECTING。
TRACKING → 低置信度、非法框、中心突跳或面积变化超限 → LOST。
LOST必须重新拖框才能TRACKING；SELECT EYE可重置任何选择状态并增加session。
按钮必须同一按钮按下/释放，拖出不触发。TRACK ON/OFF只改变运动意图，EXIT请求退出。旧session不能显示温度。

## 温度状态

| 当前状态 | 条件 | 结果 |
| --- | --- | --- |
| 任意 | 禁止跟踪/无目标/超时/未标定/ROI覆盖不足/运动未稳 | INVALID，清空窗口 |
| INVALID | 所有资格成立 | STABILIZING，启动稳定计时 |
| STABILIZING | 稳定满stabilization秒 | COLLECTING，只接收稳定后采集帧 |
| COLLECTING | 足够不同新帧且P90跨度≤temperature_span | VALID，发布窗口均值 |
| VALID | 仍满足资格 | 滑动更新；重复帧不增加样本 |
| 任意 | 乱序/坏帧/未来帧/旧帧 | INVALID，撤销数值 |
| 任意 | 单调时钟逆行 | INVALID并抛错，主进程退出 |
| VALID | 新窗口温度不稳定 | COLLECTING，不显示上次有效值 |

坏点先按有限值/范围筛，再按MAD筛；不足有效像素比例拒绝。融合窗口最大10帧，每帧仅保存统计量。矩阵24×32，最新队列深度1。没有自动猜协议、无限重试或旧帧补发。

视觉/传感器是独立进程；温度失效不阻塞云台循环。视觉退出会退出主程序，视觉过期则保持当前位置、清空温度。传感器异常不自动重启，修复后重启应用。退出先关激光/清理电机，再给子进程有界join/terminate/kill，每项独立清理。主进程硬崩溃时物理失能仍取决于原硬件故障保护，不宣称Python能覆盖断电。

预算：控制默认20Hz，视觉过期0.25s，传感器过期0.6s，显示状态过期0.25s。I2C厂商阻塞调用隔离在子进程，主进程不等待它；没有自定义ISR/DMA。实际帧率、最坏循环周期、进程RSS/CPU与长时稳定性均TBD。
