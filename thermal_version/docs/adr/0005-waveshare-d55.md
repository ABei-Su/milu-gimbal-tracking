# ADR 0005：切换微雪 MLX90640-D55

接受，2026-09-22。用户明确停用旧GD32串口模块并确认D55（55°×35°）。替代ADR0004中的当前硬件选择，三进程、原模式、激光关闭和温度有效性状态保持不变。

厂家截图明确I2C、默认7位地址0x33、32×24、VCC/GND/SDA/SCL、3.3V/5V输入。官方示例ZIP已下载、CRC校验成功，树莓派main.cpp确认0x33、EEPROM校准、棋盘模式和温度换算。厂家安装脚本不在MaixCAM2执行；使用MaixPy官方MLX90640Celsius适配，避免树莓派驱动/路径混用。原理图与实物修订仍需对应，按3.3V供电连接。

thermal.json明确设mlx90640_i2c、sensor_confirmed=true、D55视场角。confirmed表示模块类型/公开接口已确认，不表示接线或实机验收通过。保留alignment_confirmed=false。dataclass缺省仍保守保持旧值，兼容旧配置的拒绝行为；部署读取完整thermal.json，不依赖隐式新缺省。旧pending_uart仍可读取但不再作为当前部署选择。

新增隔离传感器检查工具：只启动传感器进程，不触碰电机/GPIO/相机；有全局截止时间和有限样本数，输出全场范围和ROI统计以及读取时延，SDK阻塞时结束子进程。收到不完整/坏矩阵即失败，不把合理数值当成自动校准通过。新增适配器契约、配置视场和超时测试。

保持8Hz刷新设置与5帧窗口初调值；阵列子页合成实际帧率与I2C速率由官方驱动/系统决定，板上测量后再调高。全局超时与主控制隔离保证温度读取不会拖住云台。
