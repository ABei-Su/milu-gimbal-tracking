# ADR 0006：识别连续性与评估效率

接受，2026-09-22；同步原版与测温版复用的milu核心。目标：在短时置信度波动时继续已有目标，减少重复计算并提供有许可的打印材料。非目标：不把伪标签一致率称为物种准确率，不改变电机闭环/限位，不用插值框或旧温度冒充新观测。

计划与验收：先添加复现弱置信度断跟踪的测试；实现有界连续跟踪及激光门控；缓存一次模型推理完成阈值评估；制作6张A4打印照片；两个工程完整检查并重新打包。

保持新目标confidence默认0.65。新增track_confidence默认0.4，实际检测阈值为min(confidence,track_confidence)。弱框仅能延续新鲜的已有目标，必须与前框归一化IoU>=0.3、面积比0.5..2、位置在原关联半径内，且候选唯一。距离上次强框不能超过stale_after（默认0.25s），防止弱框无限续命。多个强候选仍沿用原保守歧义标记；弱框强制歧义且light_eligible独立检查confidence，不能点亮激光。空帧不补造目标，过期/倒序规则不变。

目标选择从排序改为单次min扫描，保存原稳定选择顺序。新参数允许显式设等于confidence关闭弱跟踪。旧配置加载新增默认，改变行为在本ADR/CHANGELOG明确记录。

评估阈值多次运行同一模型改为每张图片一次低阈值预测、按score筛选缓存。前提：同一模型、预处理、NMS IoU和max_det一致；当前单类别无需跨类别NMS。验证报告标明机器候选标签、已使用过的开发测试集及PC浮点模型限制。权重本轮不盲目重训，缺少人工验收框和混淆鹿种负样本仍是准确率证据缺口。

打印从现有许可照片中选取，附逐页来源、许可与数据集划分。用于打印联调，不视为全新独立测试。测温不能在纸上检验真实鹿眼温度。
