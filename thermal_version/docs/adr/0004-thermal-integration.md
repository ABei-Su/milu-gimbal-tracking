# ADR 0004：独立测温集成版

2026-09-22补充：以下硬件选择属于0.1历史记录，已被ADR0005微雪D55替代；其余架构继续适用。

接受，2026-09-22。按新增技术路线第一阶段实现触屏框选眼周、跟踪、温度阵列处理、ROI统计/滤波、板载屏幕及有效性判断。基于原0.3完整复制到独立目录，不从父目录导入。原observe/track/paper由base_main保留，main默认测温、显式--mode运行原模式。

## 硬件与协议决定

最新商品截图选择A型110°×75°，板载GD32、TTL串口及USB串口；不是已确认可直接访问的裸MLX90640。默认sensor_backend=pending_uart，不猜帧头、指令、编码、校验或TTL电压。协议缺失时界面仍可跟踪，但温度明确无效。sensor_confirmed=true不能绕过pending_uart。

保留官方I2C适配作为可选路径：MaixCAM2 I2C6 A0/A1有官方依据，但用户这块GD32板的I2C是否可由外部主机访问TBD。供电、地址、上拉、总线所有权未确认前不启动I2C。详细截图证据、矛盾项和接口缺口见thermal-hardware.md。

眼周使用官方MixFormerV2及系统模型/root/models/mixformer_v2.mud，关闭自动全局找回；人工框选不是自动眼周检测。热像和RGB中心只在固定距离标定，不能把大鹿框冒充眼周。

## 架构与恢复

主进程独占电机/GPIO，视觉进程拥有相机/触屏/显示，传感器进程拥有传感器。最新队列长度1。主进程不等待红外I/O，阻塞传感器由时间戳失效及有界join/terminate/kill隔离。测温入口始终关激光，退出独立清理；视觉退出为故障，传感器断流仅温度无效。详细状态与拒绝码见thermal-state-machine.md。

稳定资格包含人工session、新鲜视觉、标定、ROI覆盖、居中、软件参考低速、实测速度和反馈到位、新鲜红外帧。重复帧不增加样本；只融合稳定后采集的帧。换目标/离心/丢失/坏帧/超时清空结果。

3×3或5×5ROI执行范围筛选、MAD异常点剔除、P90，最后5–10帧均值，同时显示筛选后ROI最大/均值。结果为表面温度，没有核心体温换算、疾病诊断或发热阈值。

## 验证与兼容

复用完整原版控制测试，新增纯状态、触屏、坏数据、重选、失效显示、传感器断流、进程退出与激光关闭的离线验证。与实际板端SDK/硬件联调分开记录。传感器解码待协议或原厂软件通信取证，不能宣布当前商品已接通。

Wi-Fi健康平台和专用眼周检测训练属于原技术路线后续阶段，未在本阶段实现。两个模式不并发争用相机，测温光轴参数用thermal_gimbal.json独立保存。
