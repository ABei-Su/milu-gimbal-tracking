# 0.3 平滑控制与上板调试

2026-09-22。优化仅涉及MaixCAM2的软件控制器和诊断日志，F32C原厂固件、内部PID、模式3、引脚、ID及识别模型未改。新配置兼容旧字段，新增项缺失时采用默认值。

## 修复内容

1. **低速不再丢失小位移。** 旧版每周期以0.1°反馈重算位置，低于一个量化台阶的变化容易永远归零。现在保留浮点位置参考，仅在协议输出时量化，同时限制参考相对反馈的超前量，避免堵转积累。
2. **两轴独立居中。** 每轴分别判定进入/退出死区，已居中轴不会因为另一轴偏离而不断微调。回差避免框在死区边缘晃动时反复启动。
3. **启停和换向缓变。** 软件参考同时限制速度、加速度及加加速度；中心附近降低控制强度并逐渐减速。光点资格还要求参考速度≤settle_rate，不能在参考仍明显运动时判定稳定。
4. **接近边界提前减速。** 根据软件限位、剩余超前预算及加速响应估计允许速度；硬限幅仍保留，不依赖模型保证机械安全。
5. **低帧率与控制时序分开。** 滤波只在新采集帧更新；复用旧帧不会重复当新证据。超过控制间隔上限、目标丢失/过期、目标切换或反馈突变时重新对齐参考。

这里的速度、加速度约束作用于软件位置参考，不是电机轴的实测速度/加速度。目标失效、重建参考、硬限位及硬速率保护优先，可能主动打断平滑；不为保持曲线漂亮而延长旧目标动作。0.1°协议台阶依然存在，无法靠软件宣称实际运动完全连续。

## 新参数

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| max_jerk | 400°/s³ | 限制加速度改变速度，减小启动/换向突变 |
| velocity_tau | 0.15s | 速度请求响应时间；较大更柔和，也更迟滞 |
| max_lead | 2° | 软件位置参考相对当前反馈的最大超前量；有提前减速 |
| max_control_gap | 0.2s | 控制主循环长暂停后取消原运动参考 |
| deadband_hysteresis | 0.008 | 退出死区比进入死区多出的归一化误差 |
| settle_rate | 0.25°/s | 判定稳定时允许的最大软件参考速度 |

原max_rate=12°/s、max_accel=60°/s²、控制20Hz、首轮±10°保持。边界/超前预算可能使实际参考速度低于max_rate，max_rate是上限不是固定运行速度。

## 复现与检查

```powershell
.venv/Scripts/python.exe tools/verify.py
.venv/Scripts/python.exe tools/benchmark_servo.py
.venv/Scripts/python.exe tools/plot_servo.py
```

最后一步需要PC训练环境的matplotlib，板端不需要。对照结果在outputs/smooth_servo/report.json与各场景CSV；comparison.png/svg可直接查看。tools/servo_v020.py为冻结旧版，仅供PC仿真，部署包不包含它。

仿真假设：20Hz控制，命令与反馈均0.1°量化，一阶电机滞后0.04–0.18秒，视觉8–20FPS、延迟50–100ms，像素高斯噪声0–4；包含短时丢帧、越出软件限位的目标及返回。它不是实测电机辨识模型。固定seed42的详细比较见smooth-benchmark.md；移动场景另以seed7/123回归验证。

## 更新到板子

旧版部署包备份为dist/milu_maixcam2_v0.2.0.zip，新包仍为dist/milu_maixcam2.zip。停止板端程序，备份自己的config.json与校准文件，再上传新main.py、milu/和app.yaml。模型三件套无需更换；新包仍带模型便于首次完整安装。

旧config.json可以继续使用；若已调过方向/引脚/光轴，不要直接用默认config覆盖。按上表增补新字段即可。程序默认observe，先用track测试纸靶移动和停止，再测试paper。

调参顺序：先确认方向/反馈与支架固定；感觉起停仍硬，降低max_jerk或增大velocity_tau；移动目标跟不上时先看frame_age，再微调gain/velocity_tau。不要同时提高gain、max_rate和max_lead。中心轻微摆动可适当增大回差，但会增加停留误差。

日志新增goal、v_ref、limited、rebase。v_ref是软件参考速度，不能当实际转速；持续limited需检查限位/负载/反馈，不应直接放大角度保护。厂商内环PID需实物辨识后再调，本次未自动写电机参数。

尚需实机测量：装上相机和激光的负载惯量、轴摩擦/松动、内环响应、串口实际周期及图像时延。没有这些数据，不能承诺所有安装条件下均丝滑或已达到最佳。
