# ADR 0009: Bounded image age compensation
2026-10-12 video evidence: control ~39Hz, vision16-18Hz, capture/inference44-50ms, poll5-13ms. User confirms smooth correct motion and requests lower delay/higher speed.
Keep current model and actual capture timestamps. Add optional prediction_horizon (default0 for compatibility, deployment60ms, permitted0..100ms). Estimate filtered image-error velocity only on new captures with an80ms velocity filter. Extrapolate by min(frame age,horizon), cap each-axis correction at2.5% image dimension; no prediction in center deadband. Reset on target loss/rebase/switch. This is relative image motion, not world velocity; it may overshoot on sudden reversals. No stale-frame validity extension.
Deployment50Hz, rate ceiling42, accel240, jerk4000, gain3.6, image filtering15ms. Actual speed remains shaped and feedback-dependent. Existing motor bounds/timeout unchanged; no new stop states. Verify repeated frames, clamps, reset and legacy disabled behavior; hardware acceptance pending.
