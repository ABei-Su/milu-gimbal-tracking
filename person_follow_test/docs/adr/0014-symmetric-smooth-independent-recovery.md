# ADR0014: Symmetric smoothing and axis-local feedback recovery
User reports 0.3.0 tracks well but jerks and requests same algorithm for both axes. 47 log samples: median48.7Hz control,16.8FPS vision,79ms frame age; one sampled feedback_discontinuity clears both axes. Logs are1Hz and cannot attribute every physical jerk.
Fix feedback discontinuity recovery to rebase only offending axes. Preserve other axis reference/velocity/acceleration, filter timestamps and normal update. Genuine loss/target change/time-gap still resets both. No threshold relaxation. Tests reproduce pitch jump stopping yaw, and now assert yaw continuity and pitch rebase.
Deployment symmetric: yaw overrides0 and gain multiplier1; common rate42, acceleration180, jerk2400, velocity response70ms, image smoothing25ms, prediction30ms, lead5. This prioritizes smoothness over prior aggressive yaw peak speed. Preserve startup face-interruptible search and limits. Actual loaded response requires field test; no motor PID/current change.
