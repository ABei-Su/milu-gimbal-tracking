# ADR0018: Optional yaw soft limit
User explicitly requests removing yaw +/-90 degree protection. Add yaw_limit_enabled default true for old configurations; deployment false. Keep configured yaw_limit for re-enabling. Effective yaw boundary is infinity only inside policy; all command/feedback inputs must remain finite. Skip angular quantization clamp for unbounded yaw; F32C position encoding still validates absolute cumulative protocol range before either axis is sent. Pitch limit, rate/acceleration/jerk, feedback timeout, startup search and fault cleanup unchanged. No automatic angle wrap or origin reset. External camera cables may wind on repeated turns. Test movement and feedback past +/-90 and +/-360, pitch rejection, and default bounded compatibility. Hardware validation pending.
