# ADR 0004 UART2 for motor communication
Accepted 2026-10-12 at user request. USB TTL controls both motor IDs 1/2, while UART4 queries receive no bytes; UART4 local loopback passed. A damaged UART4 is not established.
Select B0 UART2_TX, B1 UART2_RX, /dev/ttyS2 at 115200 8N1 in shipped config and Settings defaults. Official mapping: https://wiki.sipeed.com/maixpy/doc/en/peripheral/uart.html . Keep bounded query-only default and listener cleanup, protocol, limits and fault handling. No automatic motion after diagnosis.
Move the proven TTL TXD wire to B0 and RXD wire to B1, with common GND; disconnect TTL and old A21/A22 wiring while power is off. Board response remains TBD. Rollback requires restoring all five UART config fields and matching wiring.
