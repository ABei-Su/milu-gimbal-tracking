# ADR 0011: 45-degree startup lift and fresher control inputs
2026-10-13 user explicitly requests 45 degrees upward from drooped startup pose. Set startup_pitch_lift45 (validation0..45), rate6 degrees/s. Same initial-minus-angle convention, yaw hold and bounded startup trajectory; completion before vision start. This is relative motion on every launch, not absolute level zero. Search means face acquisition at the lifted pose, not autonomous motor scanning.
84 supplied log samples: median control48.7Hz, vision16.8FPS, capture/inference45.95ms, frame age97ms, poll6.65ms (max18.2ms). No sampled control-gap/discontinuity rebases. Preserve tuned gains/derivative limits. Move feedback poll before the queue read so frames arriving during UART wait can be used in the same tick. Poll also monitors the motor during vision startup. Deadline and independent cleanup unchanged. No claim that inference latency is eliminated.
Regression tests enforce poll-before-receive, 45-degree lift target/yaw hold/deadline and validation; full suite required. Actual load and latency remain field acceptance.
