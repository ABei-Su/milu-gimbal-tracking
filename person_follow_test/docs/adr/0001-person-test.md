# ADR 0001 独立人体跟随测试
状态：接受，2026-10-12。用户要求保留麋鹿版，批准独立人体测试版。
复制成熟控制核心，不修改原工程。板端入口仅 observe/track，默认 track。模型使用板上官方 COCO YOLO11 /root/models/yolo11n.mud，只接受 person 类。模型权重不随源码包重复分发；缺失时启动明确报错，安装官方 MaixCAM2 模型后重试。
视觉进程只投递人体框，主进程独占电机。保留 F32C 协议、±10°限位、反馈保护、目标关联及平滑参考。纸靶模式删除；底层 LaserOutput 拒绝任何开启请求，运行器仅关断。人体实验拔掉激光供电。
不增加人脸识别或身份识别，遮挡/交叉可能换人。没有增加测温。公共电机协议不变。旧光源参数仅用于配置兼容，不再授权点亮。
回退：退出人体应用，运行原独立应用。原文件 SHA256 保存在 original_hashes.json，可检查未改变。
