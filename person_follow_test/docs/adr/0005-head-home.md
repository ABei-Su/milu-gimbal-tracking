# ADR 0005 Head follow and calibrated startup home
Accepted scope from user 2026-10-12: calibrated level-forward mechanical zero already set in vendor software. Original deer/thermal excluded.
Evidence: supplied run has target_lost and +/-10 degree saturation; current controller re-captures sagging measured position each missing frame. Desktop recording crops heads at top. Firmware distinguishes mechanical zero (query kind 2) from cumulative angle (kind 1).
Implement loss hold once per missing-target episode, rebase once on reacquisition. Add optional mechanical-zero homing via shortest wrapped delta, fixed-origin tracking, bounded rate/travel/timeout and tracking-error guard. Home command never clears encoders or writes motor Flash. HOMING succeeds only after stable feedback near target; failure disables both motors. Stop callback cancels homing.
Startup model validation precedes actuation. Homing does not require detecting a person. A face detector uses actual face boxes, never an estimated slice of person box. Face/AX model availability is a deployment prerequisite, not silently replaced by person detection. Enlarged travel requires physical clearance; fixed software limits do not prove clearance. Heavy-load holding torque and reboot persistence of calibrated zero remain hardware acceptance items.

User subsequently confirmed +/-35 yaw and +/-25 pitch clearance. Deployment enables home and face auto discovery; model absence explicitly blocks activation. No downloaded AX face weights yet; field model inventory required. 407 public detail identifies MaixCAM package, so it was not deployed to MaixCAM2.
