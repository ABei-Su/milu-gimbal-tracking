# 硬件契约

资料来源为原Word/Excel、WHEELTEC电机/二维云台手册及STM32F4绘图例程，具体位置见 vendor-evidence.md。硬件未连接，以下区分厂商默认、软件选定和未测事实。

| 项目 | 约定/来源 |
| --- | --- |
| 主板 | 用户暂定MaixCAM2；SoC AX630C；板修订、eMMC/SD版本、镜头、系统和SDK版本 TBD |
| UART | TTL3.3V、115200 8N1，完整帧，使用2ms空闲间隔 |
| 板端引脚 | 选定B0 UART2_TX、B1 UART2_RX、/dev/ttyS2；MOS选定A4 GPIOA4 |
| 轴 | 厂家默认下轴ID1，上轴ID2；实物如改过ID需恢复/另行适配 |
| 方向 | F4例程向右=-1、向上=-1；图像y向下，本配置按用户左右反向实测改为yaw=+1、pitch=+1，俯仰方向尚待验收 |
| 模式 | 多圈直通位置3；速度30RPM，应用另限12°/s和60°/s² |
| 零点 | 用户已在厂家软件校准水平机械零位；读取单圈机械角度与累计角度，限速回到最近的机械零位后建立固定跟随原点；不清编码器/不写Flash |
| 限位 | 厂家示例±90°软件保护；用户确认左右±35°、上下±25°有机械/线材余量；回正路径仍需实测 |
| 时序 | 厂家启动1500ms、帧间2ms、反馈500ms；应用每次查询80ms截止 |
| 电机电源 | 手册8–15V，清单12V电池；满电电压、极性/接线需按实物确认 |
| 光源 | 清单650nm、<1mW、3.3–5V；MOS高有效为配置假设，实际型号/有效电平 TBD |
| 光轴 | 与镜头固定，aim_x/y由固定距离测量；FOV默认60°×45°为初调假设 |
| 故障状态 | 尝试关灯、失能；物理停机和掉电时MOS默认关闭需要硬件保证 |

厂商包存在滑环1A/1.5A两种记载，接口电源3V3/5V标注差异；原项目峰值2A与手册单电机1.5A口径不同，未猜测为统一规格。禁止热插拔，无反接保护。

驱动由Linux/MaixPy提供；本项目无裸机时钟/复位/ISR/DMA代码。系统看门狗、板级电源复位行为、CPU/内存峰值、启动时间与温升为实测TBD。未配置自制bootloader/OTA，不修改系统分区。

协议大端、速度有符号RPM、角度有符号0.1°，XOR BCC覆盖帧头至数据末尾，反馈9字节。反馈角度/10、母线电压/100。地址设置BCC和位置KI示例排版疑点所涉及命令不实现，也不实现恢复出厂/参数保存。

2026-10-12 实测进展：用户 UART2 两轴各三次 VALID；厂商上位机两轴可运动。重载保持扭矩、回正轨迹、俯仰符号和头脸检测帧率未验收。人脸模型须为 MaixCAM2 AX；不支持背头保证，不识别人身份。

0.2.1: 用户确认机械可转360度；跟随限位改为双轴±90度，最短路径回零允许180度/45秒。先回零后启动视觉，启动不主动失能；故障及退出仍失能。实际负载回正待板端验收。

2026-10-12 补充：用户确认未完成保存零点/掉电复查。先按厂家手册分别调试两个电机，在镜头水平朝前的姿态设置机械零点并保存设备参数；保持姿态断电重上电，读取机械角度应接近0度（359.9度也接近零）。未复查前不重复自动回零。跟随方向符号不影响回零坐标。

0.2.3 当前部署：home_enabled=false，startup_pitch_lift=10；STARTING→HOMING执行相对抬头（2号减10度，1号原地保持），到位→READY并启动视觉。该点仅为软件跟随原点，不是水平零位。速率3度/秒，原超时和偏差保护保留；每次运行重复相对动作。详见ADR0007。

0.2.4 跟随部署目标40Hz，max_rate=36、max_accel=180、max_jerk=2400、max_lead=5；电机速度命令仍30RPM。UART每次查询仍80ms截止，实测poll_ms可能让实际频率低于目标；反馈超时、丢目标保持、角度限位不变。

0.2.5 部署50Hz，速度上限42度/秒，加速度240、加加速度4000；其他电气协议与启动动作不变。实际频率和重载跟随待实测。

0.2.7：用户授权启动相对抬头45度，速率6度/秒，1号保持。到位后开启视觉并等待人脸，不自动扫描。控制每轮先查询反馈再取最新检测消息；视觉启动期间也查询反馈。其余轨迹参数不变，详见ADR0011。

0.2.8 用户要求启动相对抬60度、速率仍6度/秒；俯仰跟随参数保持，后续重点调优底部左右轴。详见ADR0012。

0.3.0：视觉先启动，首个新鲜帧就绪后允许启动搜寻。HOMING相对抬头分支可由有效人脸提前结束并捕获实测跟随原点；取消/超时/视觉错误走既有故障清理。机械回零分支不受检测打断。左右逐轴约束与上下独立，详见ADR0013。

0.3.1 两轴共用平滑参数；反馈偏差恢复仅作用于相应轴，另一轴保持连续更新。丢目标/故障退出规则不变，详见ADR0014。

0.3.2 搜寻最大相对90度，途中检测提前终止；两轴请求平滑40ms，超时和故障规则不变，详见ADR0015。

0.3.3：跟随左右范围改为相对捕获起点±180度，上下±90度；到限位保持该轴边界，可反向退出，另一轴独立运行。angle_limit_axes报告具体角度限位轴，修复目标饱和漏报。撤回40ms请求滤波，保留原运动整形和搜索90度。原点不自动重置，不是无限旋转；板端验收待完成。详见ADR0016。

当前回退部署0.3.1：取消请求滤波，搜索60度提前识别停止、两轴跟随±90度，其余恢复ADR0014。此记录覆盖0.3.2/0.3.3部署说明，见ADR0017。

当前部署：用户要求取消左右软件角度限位，yaw_limit_enabled=false；不在±90/180/360度停转。不改变当前平滑控制参数，上下±90度、启动搜索60度及提前识别停止保持。旧配置默认仍启用限位；设置true可恢复yaw_limit。输入有限数、通信超时和F32C累计角度协议范围检查保留；不允许无限数指令。连续绕转可能缠绕外接线。主机135项测试通过，实机待验收。详见ADR0018。


当前左右温和调优（yaw-gentle-20261013）：yaw_max_lead=6度，yaw_gain_multiplier=1.08；其余平滑参数、上下控制、启动60度及人脸提前结束保持。左右角度限位仍关闭。日志lead_deg为目标减实际角度，不是限位事件计数。更大领先可能增加超调，实机平滑/延迟改善待验证。恢复yaw_max_lead=0、yaw_gain_multiplier=1即回到本次调优前响应。完整离线检查137项通过，见ADR0019。


当前部署yaw-gentle-v2-20261013：左右领先6→6.5度、增益1.08→1.12，沿用已获用户好评版本的小幅调参方式。速度/加速度/加加速度、上下参数、搜索60度及丢目标规则均不变，左右角度限位仍关闭。最新106条日志中有效目标最大左右差值5.308度；丢脸保持误差不用于放宽运动参数。实机卡顿/延迟改善待复测，可能增加超调。回退设yaw_max_lead=6、yaw_gain_multiplier=1.08，见ADR0020。
