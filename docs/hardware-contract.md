# 硬件契约

资料来源为原Word/Excel、WHEELTEC电机/二维云台手册及STM32F4绘图例程，具体位置见 vendor-evidence.md。硬件未连接，以下区分厂商默认、软件选定和未测事实。

| 项目 | 约定/来源 |
| --- | --- |
| 主板 | 用户暂定MaixCAM2；SoC AX630C；板修订、eMMC/SD版本、镜头、系统和SDK版本 TBD |
| UART | TTL3.3V、115200 8N1，完整帧，使用2ms空闲间隔 |
| 板端引脚 | 选定A21 UART4_TX、A22 UART4_RX、/dev/ttyS4；MOS选定A4 GPIOA4 |
| 轴 | 厂家默认下轴ID1，上轴ID2；实物如改过ID需恢复/另行适配 |
| 方向 | F4例程向右=-1、向上=-1；图像y向下，所以本配置yaw=-1、pitch=+1 |
| 模式 | 多圈直通位置3；速度30RPM，应用另限12°/s和60°/s² |
| 零点 | 每次启动读反馈建立软件零点；不清编码器/不写Flash |
| 限位 | 厂家示例±90°软件保护；初调配置±10°，实际安装机械余量 TBD |
| 时序 | 厂家启动1500ms、帧间2ms、反馈500ms；应用每次查询80ms截止 |
| 电机电源 | 手册8–15V，清单12V电池；满电电压、极性/接线需按实物确认 |
| 光源 | 清单650nm、<1mW、3.3–5V；MOS高有效为配置假设，实际型号/有效电平 TBD |
| 光轴 | 与镜头固定，aim_x/y由固定距离测量；FOV默认60°×45°为初调假设 |
| 故障状态 | 尝试关灯、失能；物理停机和掉电时MOS默认关闭需要硬件保证 |

厂商包存在滑环1A/1.5A两种记载，接口电源3V3/5V标注差异；原项目峰值2A与手册单电机1.5A口径不同，未猜测为统一规格。禁止热插拔，无反接保护。

驱动由Linux/MaixPy提供；本项目无裸机时钟/复位/ISR/DMA代码。系统看门狗、板级电源复位行为、CPU/内存峰值、启动时间与温升为实测TBD。未配置自制bootloader/OTA，不修改系统分区。

协议大端、速度有符号RPM、角度有符号0.1°，XOR BCC覆盖帧头至数据末尾，反馈9字节。反馈角度/10、母线电压/100。地址设置BCC和位置KI示例排版疑点所涉及命令不实现，也不实现恢复出厂/参数保存。
