# ADR 0003 有界平滑视觉伺服

状态：接受，2026-09-22。用户要求继续优化二维云台平滑度。

发现0.2版问题：居中时硬清零速度绕过加速度限制；两轴共用居中判断造成已居中轴跟随另一轴抖动；每周期从0.1°量化反馈重新积分，丢失细小位移；重复使用旧帧更新滤波使低帧率和控制周期相互耦合。

决定：保留F32C模式3、方向、UART/GPIO、限位及检测模型。采用每轴浮点位置参考、死区回差与柔和误差过渡；新帧时按采集间隔更新滤波；参考速度用有界加速度/加加速度整形，并按剩余限位距离提前减速。浮点参考相对反馈限制最大超前量，防止执行器堵转后命令积累。新增参数带默认值，旧配置仍可读取。

执行器状态、光源模式不变。目标丢失/过期、generation切换、循环长暂停触发参考重建（与实测位置对齐）；这些保护事件优先于平滑，不以平滑名义继续追旧目标。普通TRACKING内满足速率/加速度/加加速度限制；硬限位、超前量保护、重建可打断该连续性。光源居中资格还要求参考速度接近零。

验证先写回归测试复现旧问题，再增加含0.1°命令/反馈量化、电机一阶滞后、视觉低帧率、延迟、噪声及短时掉帧的确定性对照仿真，比较速度变化、跟踪误差、超调和死区反复启停。冻结0.2控制器仅供基线对比。无实际负载参数，仿真指标不代表实机性能。

回滚：恢复0.2控制器及配置默认；保留模型和厂商固件不变，不修改电机PID/Flash。新版本更新部署包，版本0.3.0。
