# ADR 0002 MaixCAM2 运行器与纸靶实验
状态：接受，2026-09-21。用户指定暂定 MaixCAM2，完整实现纸靶实验链路并保留迁移能力。

相机和 YOLO11 放在独立子进程，仅传最新检测；主进程唯一拥有 UART、GPIO。dual_buff=False 保证图像与结果时间对应。采用厂商例程的多圈直通模式 3、30 RPM、2 ms 帧间隔、500 ms 超时、使能后反馈重建软件零点。向右=-1、图像向下=+1 来源 draw_circle_task.h；±90°是软件保护，首轮默认±10°。

硬件状态集中转移，任何超时/部分串口写入锁定 FAULT，不自动重启或写 Flash。先共同验证两轴目标，再串行发送；任一失败尝试失能两轴，光源先关。启动先失能，再配置和原地保持，退出关灯失能。物理下垂与断线需要机械支撑/电源开关。

观察模式禁用光源；纸靶模式由操作员选择、定义实验区域，只有唯一目标、新鲜检测、居中且电机到位时才输出限时脉冲。故障和退出关闭。Python 无法覆盖断电或强杀进程，MOS 默认关闭的硬件电路必须保证。

只用授权 Elaphurus davidianus 图像，记录来源。机器候选框需标记伪标签，模型结果不得冒充人工验收。普通鹿检测不可称为麋鹿物种识别。板上 NPU 转换和实机测试必须单独报告。
