# ADR 0001 先实现独立于视觉板的离线参考核心

状态：接受，2026-09-21。

用户尚未选择 K230 或 MAXICAM2，现有目录只有资料，没有软件项目。文档暂定 K230，用户最新指示优先。具体 SDK、引脚、模型和机械限位未知。

决定：以 CPython 标准库实现可测试参考核心，隔离检测框、控制策略与 F32C 协议；先提供离线仿真，不猜测板端 SDK。使用多圈位置 T 轨迹模式协议作为首轮联调候选，真正使能/模式/速度初始化由未来硬件会话负责。控制器输出为相对于已确认机械原点的绝对位置，实机必须从反馈位置初始化，禁止把软件默认零点视为实机姿态。

影响：现在即可核对协议与控制策略，但还不能直接部署到任一视觉板。板端移植不承诺直接复制运行。速度、视角比例、方向及角度上限必须标定。替换控制模式或增加硬件状态机需另写 ADR。后续若需 MCU，应将受测策略迁移到固定宽度 C 接口并新增目标构建和板上证据。
